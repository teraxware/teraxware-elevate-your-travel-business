# Teraxware: Elevate Your Travel Business

Objetivo

Diseña una landing page SaaS premium para una empresa de tecnología turística llamada Teraxware, especializada en software para agencias de viajes, operadores turísticos, DMCs y empresas de turismo.

La estética debe ser similar a las landing pages modernas de Stripe, Linear, Framer y la referencia adjunta.

Estilo Visual

Diseño minimalista y premium.

Fondo claro con secciones destacadas usando gradientes azul profundo, violeta y rojo corporativo.

Mucho espacio en blanco.

Tipografía moderna tipo Inter o Montserrat.

Mockups realistas de escritorio, móvil y dashboards flotando.

Animaciones suaves.

Efectos glassmorphism ligeros.

Bordes redondeados.

Apariencia tecnológica, innovadora y corporativa.
